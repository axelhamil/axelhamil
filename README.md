## About

**Axel Hamilcaro, Développeur Web Fullstack | Next.js | React | Node.** Freelance based in Touraine, France, working 100% remote. I design multi-tenant B2B SaaS and custom web applications in TypeScript, on a Clean Architecture and DDD foundation.

7+ years building for the web. Four of them at [Civitime](https://axelhamilcaro.com/portfolio/civitime), an EdTech B Corp, going from developer to tech lead. Freelance since 2024, with 10+ projects shipped.

Professionally I operate through my organization [EIAxelHamilcaro](https://github.com/EIAxelHamilcaro). This profile is my personal lab: open-source experiments, libraries, and starters.

<br />

## Selected work

- [ScormPilot](https://axelhamilcaro.com/portfolio/scormpilot) : multi-tenant SCORM e-learning SaaS, 5 apps shipped solo in a Turborepo monorepo, 99.9% uptime.
- [Civitime](https://axelhamilcaro.com/portfolio/civitime) : B Corp CSR platform, 250,000+ employees, tech lead for 4 years, RAG-based AI.
- [OpenUp](https://axelhamilcaro.com/portfolio/openup) : all-in-one link management SaaS, Cloudflare edge under 50ms, iOS/Android/PWA.
- [Billetterie](https://axelhamilcaro.com/portfolio/billetterie) : 2D/3D seating chart with WebSocket sync under 200ms, shipped solo in a month.
